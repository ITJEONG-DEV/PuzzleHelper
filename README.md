# 퍼즐 도우미

스도쿠·노노그램·가쿠로·지뢰찾기·스타 배틀·칼큐도쿠·텐트와 나무·킬러 스도쿠 등을 풀다가 막히면 다음 한 단계를 힌트로 알려주는 PWA. 브라우저에서 쓰거나 휴대폰 홈 화면에 앱으로 설치할 수 있고, 설치 후에는 오프라인에서도 동작한다.

**사용하기**: https://itjeong-dev.github.io/PuzzleHelper/

첫 화면에서 게임을 고른다. 게임 화면 제목 줄의 앱 모음 버튼으로 다른 게임이나 목록으로 바로 간다. 게임 화면은 그 게임을 열 때만 내려받는다.

## 게임

| 게임 | 주소 | 할 수 있는 것 |
|---|---|---|
| 스도쿠 | `#/sudoku` | 문제 직접 입력·텍스트 붙여넣기·사진 입력, 난이도(하·중·상·최상) 랜덤 문제, 후보수, 단계별 힌트 |
| 노노그램 | `#/nonogram` | 단서 입력·사진 입력, 크기(5~20)·난이도(쉬움~최상) 랜덤 문제, 단서 숫자별 완료 표시, 단계별 힌트 |
| 가쿠로 | `#/kakuro` | 크기(6~12)·난이도(하·중·상·최상) 랜덤 문제, 칸별 합 조합 도움말, 후보수, 단계별 힌트 |
| 지뢰찾기 | `#/minesweeper` | 찍지 않고 풀리는 판(초급·중급·고급 × 하·중·상), 열기·깃발·? 표시, 실행 취소, 단계별 힌트 |
| 스타 배틀 | `#/starbattle` | 행·열·영역마다 별 1개(5·6·8·9칸), 난이도(하·중·상) 랜덤 문제, ×·별 표시(끌어서 여러 칸 ×), 단계별 힌트 |
| 칼큐도쿠 | `#/calcudoku` | 켄켄과 같은 규칙. 크기(4~7)·난이도(하·중·상) 랜덤 문제, 상자별 가능한 숫자 도움말, 후보수, 단계별 힌트 |
| 텐트와 나무 | `#/tents` | 크기(6·8·10·12)·난이도(하·중·상) 랜덤 문제, 잔디·텐트 표시(끌어서 여러 칸 잔디), 행·열 텐트 수 다 맞으면 흐리게·넘치면 빨갛게, 단계별 힌트 |
| 킬러 스도쿠 | `#/killer` | 9×9, 난이도(하·중·상) 랜덤 문제, 점선 상자 합·45 규칙 힌트, 후보수, 단계별 힌트. 기법으로 막히는 곳에는 숫자를 몇 개 미리 준다 |

공통
- 모든 랜덤 문제는 답이 하나이고, 찍지 않고 논리로 끝까지 풀린다. 난이도는 풀 때 꼭 필요한 가장 어려운 기법으로 정한다.
- 힌트는 누를 때마다 한 단계씩 더 알려준다: 어디를 볼지 → 무엇을 찾을지 → 칸과 이유(`판에 적용`).
- 다 풀면 판 위에 안내가 겹쳐 뜬다(판이 밀리지 않음).
- 푸는 중에는 `새 게임`, `같은 조건으로 다시`로 이어서 푼다.
- 진행 상태는 브라우저에 게임별로 자동 저장된다.
- 새 버전이 배포되면 화면 아래에 새로고침 안내가 뜬다.

## 개발

```bash
npm install
npm run dev       # 개발 서버
npm test          # 모든 게임의 풀이·힌트·문제 만들기 테스트
npm run build     # dist/에 PWA 빌드
npm run icons     # public/icon-192.png, icon-512.png 다시 만들기
```

main에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트·빌드 후 GitHub Pages에 배포한다.

## 구조

- `src/App.tsx`: 첫 화면(게임 목록)과 주소(`#/게임`)에 따른 화면 전환
- `src/shared/`: 게임 목록(`catalog.ts`), 아이콘, 앱 모음(`AppNav`), 새 버전 안내, 판 위 안내
- `src/base.css`, `src/home.css`: 모든 화면 공용 스타일
- `src/games/<게임>/`: 게임별 화면(`App.tsx`)·엔진·테스트. 스타일(`styles.css`)은 `.g-<게임>` 안에서만 적용되어 게임끼리 섞이지 않는다
  - `sudoku/`: `sudoku/`(판·풀이·힌트·문제 만들기), `photo/`(사진에서 숫자 읽기)
  - `nonogram/`: `nonogram/`(줄 풀이·힌트·문제 만들기), `photo/`(사진에서 판·단서 읽기)
  - `kakuro/`: `kakuro/`(합 조합·줄 추론·힌트·문제 만들기)
  - `minesweeper/`: `mines/`(판·추론·힌트·판 만들기)
  - `starbattle/`: `stars/`(판·추론·답 세기·힌트·문제 만들기). 문제는 별 배치 → 영역 키우기 → 다른 답에만 쓰이는 칸을 이웃 영역으로 옮겨 답을 하나로 만들기 → 난이도 판정 순서로 만든다
  - `calcudoku/`: `calc/`(판·상자 계산·추론·힌트·문제 만들기). 문제는 라틴 방진 → 상자 나누기 → 연산 정하기 → 기법으로 끝까지 풀리는지·난이도 판정 순서로 만든다
  - `tents/`: `tents/`(판·나무-텐트 짝짓기·추론·힌트·문제 만들기). 문제는 텐트를 닿지 않게 놓고 텐트마다 이웃에 나무를 둔 뒤, 기법으로 끝까지 풀리는지·난이도 판정 순서로 만든다
  - `latin/`: 라틴 방진 계열(칼큐도쿠·킬러 스도쿠·후토시키·스카이스크래퍼) 공용 추론 엔진(`engine.ts`), 힌트 설명(`hints.ts`), 게임 화면(`LatinApp.tsx`)
  - `killer/`: `killer/`(판·45 규칙·문제 만들기). 문제는 스도쿠 정답 → 숫자가 겹치지 않는 2~5칸 상자 → 기법으로 막히면 막힌 칸에 숫자 주기 → 난이도 판정 순서로 만든다

새 게임을 넣을 때는 `src/games/<게임>/`을 만들고 `catalog.ts`·`AppIcon.tsx`·`App.tsx`의 화면 목록에 한 줄씩 더한다.
